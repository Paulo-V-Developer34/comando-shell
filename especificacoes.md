# SUPER PROJETOS

## ESPECIFICAÇÕES

1. sistema de login e cadastro
2. sistema de projeto
3. sistema de autenticação
4. sistema de criação de pastas
5. sistema de criação de validação de CPF

## FLUXO

1. Fazer login (chamando cpf.sh e login.sh e guardando os dados em .database)
2. Entrar em um projeto (chamando auth.sh verificando .database e o .database dos projetos)
3. Criar um projeto (chamando criar-projeto.sh)
4. Gerenciar acesso dos usuários chamando (auth.sh verificando o .database)
5. Criar módulos (usando módulos.sh)
